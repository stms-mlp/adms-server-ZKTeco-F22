# Escudo / logo municipal

Colocá acá dos imágenes (los nombres deben ser exactos):

- `escudo.png` — logo para la barra superior. Origen 250×113; se muestra a 38 px
  de alto (se adapta solo). Fondo transparente recomendado.
- `escudo-marca.png` — escudo 500×630 usado como **marca de agua** tenue detrás
  del contenido. Fondo transparente recomendado.

Si alguno de los archivos no existe, el sistema simplemente no lo muestra (no rompe).

Subilos por FTP/administrador de archivos del hosting a la carpeta `assets/`,
o agregalos al repositorio en esta ubicación.
